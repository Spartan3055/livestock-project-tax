# Project Ledger

Free 4-H / FFA livestock project tax worksheet: https://spartan3055.github.io/livestock-project-tax/

Static site. The calculator (`calc.js`) runs entirely in the browser and saves nothing.
Educational only; not tax advice. Not affiliated with 4-H, National FFA, USDA, or the IRS.

Pushes to `main` are mirrored to `gh-pages` by `.github/workflows/publish.yml`.
